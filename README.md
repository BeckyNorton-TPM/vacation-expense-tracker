# Vacation Expense Tracker



A full-stack app to log vacation expenses in local currency,

auto-convert to USD via live exchange rates, and track running

totals by category — with support for organizing expenses by named

trip and a quick currency-check tool for on-the-spot conversions.



## Why I built this

Built to demonstrate TPM skills — scoping, planning, and execution —

on a real, working technical project.

## Stack

Flask · SQLite · React · Live currency exchange API · Claude Code



## Setup

1. Clone the repo

2. Backend: `cd backend \&\& pip install -r requirements.txt \&\& python run.py`

3. Frontend: `cd frontend \&\& npm install \&\& npm run dev`
